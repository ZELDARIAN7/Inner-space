INSTALL THIS VERSION
Unzip. Copy server\.env from your old folder into the new server folder (it keeps your
Anthropic and ElevenLabs keys). Double-click START-WINDOWS.bat.

ONE TIME
1. Install Node.js (the LTS version) from https://nodejs.org
2. Unzip this folder somewhere easy, like your Desktop.

EVERY TIME
3. Double-click START-WINDOWS.bat
   - The first time, it asks for your Anthropic key. Paste it, press Enter.
     It is saved only on your PC, in server\.env. Never send it to anyone.
   - Your browser opens http://localhost:3000 by itself.
4. Keep the black window open while you use the app. Close it to stop.

ON YOUR PHONE (same Wi-Fi as the PC)
- On the PC, open Command Prompt and type: ipconfig
  Find "IPv4 Address", for example 192.168.1.23
- On the phone's browser, open: http://192.168.1.23:3000
  (If Windows asks about the firewall the first time, click Allow.)

WHAT'S REAL NOW
Talk, Ask the Warrior and Deep Session answer with the real Claude.
If the key is missing or the internet drops, they fall back to the offline
versions, so nothing breaks.

REAL VOICE (ELEVENLABS)
Before you start: on elevenlabs.io, make sure the voice you want is in
"My Voices" (from the Voice Library, click "Add to my voices").
1. Double-click START-WINDOWS.bat. It asks once:
   - "ElevenLabs key:"  paste your key (elevenlabs.io -> profile -> API Keys), Enter.
   - "Voice name:"      type the voice name as it is in My Voices, Enter.
2. That's it. The black window says:  Voice: ElevenLabs · <the name>
To change the key or the voice later: double-click SET-VOICE.bat.
You can also hear and switch voices in the app: tap INNER SPACE 7 times -> DEV -> Voice.
Every line is made once and saved in server\cache\voice, so a meditation you do
every day costs ElevenLabs characters only the first time.

WRONG KEY?
Delete the file server\.env and run START-WINDOWS.bat again.

The single file inner-space.html still works on its own (offline mode)
if you open it directly, like before.

RECORD THE VOICE IN YOUR OWN VOICE
- With the app running (START-WINDOWS.bat), open on the PC:  http://localhost:3000/studio.html
  (or in the app: Guides -> The Voice -> "Record your voice")
- Tap Record, sound it, tap Stop. It saves straight into assets\guides\voice.
  The next session plays you instead of the tone.
- Record on the PC itself (laptop mic or a headset). A phone on Wi-Fi can't use the
  microphone over http - that's the browser's rule, not the app's.
- When you've recorded a few, zip the folder assets\guides\voice and send it to Claude:
  it comes back cleaned (noise, hum, room), warmer, and the chants with a stone-room depth.

THE SHADOW (Guides -> The Shadow)
- Works offline. With your key in, the one question it asks is written by Claude from your own words.
- Lock it with a PIN on first open: on this PC (localhost) everything is sealed with the PIN.
  Forget the PIN and the Shadow has to be wiped - nobody can open it.
- To lie down and listen: Meet a part -> pick one -> keep "Dark screen" on -> Begin.
  In Chrome you can pick a better device voice with "Choose the voice".

DEVELOPER MODE (for you)

  Tap it: AI health + real model test, open any screen, fast timers, clear data per module, wipe.

KEEP YOUR KEY when you install a new version: copy the file server\.env from the old folder.

PWA / INSTALL
- On the PC, http://localhost:3000 is a secure browser context and the service worker can install/cache the app.
- On a phone, http://<PC-IP>:3000 works for testing on the same Wi-Fi, but browsers do not treat ordinary LAN HTTP as a secure context.
  For a true installable phone PWA (service worker/offline install), serve/deploy the same folder over HTTPS.
- Voice Studio recording and DEV voice selection are intentionally local-PC actions. The normal app and ElevenLabs playback can still be used from the phone.
